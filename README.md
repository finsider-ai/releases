# Finsider Releases

Public download hub for Finsider client apps.

- **Finsider Desktop (macOS, Apple Silicon)** — `Finsider-<version>-arm64.dmg`
- **Finsider Desktop (Windows)** — `Finsider-Setup-<version>.exe`
- **Finsider Excel Agent (sideload add-in)** — `finsider-excel-agent.tgz`

Latest stable links:
